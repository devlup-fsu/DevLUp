## Editing Page Content

If you want to edit a page, **always** go to the `_layout` or `_templates` directory.

**Do not modify HTML in the root directory, or in `archive`, `board` or `projects`.**

### `_layout`

`_layout` contains all the pages in the site.
Its contents will be essentially copied and pasted over the root directory, overwriting `.html` files as necessary.

### `_templates`

`_templates` contains reusable HTML templates which can be referenced in other pages.
This is useful for things like navbars, footers, and other identical elements that need to be on every page.


## Using Template Expressions

You can use the following syntax to insert templates into your pages:

```
Some HTML here...

{{ template('footer') }}

More HTML here...
```

In this case, the site generator will look for a file called `footer.html` inside the `_templates` directory, and then replace the expression with its contents.


## Generating the Site

To regenerate all of the site pages, run the following command in a terminal:

```sh
python3 generate_site.py
```


## Assets

The `assets` directory is used to store images and documents that are featured on the site.
